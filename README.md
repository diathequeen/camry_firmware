OnePlus Nord CE4 Lite 5G ROM archive
====================================

I keep all EDL and OTA here so I wouldn't lose it anymore lol

This repo is only for saving proprietary qualcomm images like `xbl.img` or `tz.img`, **full OTA is [right here](https://sourceforge.net/projects/camry-firmware/files/)**

Hop on releases tab to download firmware.

ARB-wise (scanned `xbl.img` with sectools provided by Qualcomm):
16.0.5.700 (or lower) | 16.0.5.1000 | 16.0.5.1200 | 16.0.5.1300
unknown (lost) | 0x1 | 0x1 | 0x1
